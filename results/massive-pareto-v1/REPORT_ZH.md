# MASSIVE 最后一阶段的学习与保留

原顺序的主要发现是 **第 94 步的普通 SeqLoRA 已达到接近第 125 步的 UR 能力，并保住了更多旧能力**。交换末两语后，这一结论不能直接迁移。满足当前语要求的 Replay 仍有显著的旧语 UR 损失。下一轮可保留“学习达到同一水平时，哪些阶段仍有真实遗忘”这一问题。旧版功能方向撤回和同源优先回放暂不推进。

## 数据与统计

沿用 MASSIVE 冻结协议 及 训练提示 的槽位生成任务和作者评分器。原序 DE→AR→VI→SW→UR，换序 DE→AR→VI→UR→SW。主要曲线使用五语各 2,033 道相同源 ID 的官方开发题。只用实测的阶段起点、第 31、63、94、125 步和已有全参终点。每个值是全题槽位 Micro-F1，四旧语均值对语言等权。单语言变化相对该方法自己的最后阶段起点，跨方法差用同一题在同一评估集上配对。

同一源 ID 五语共用一次 bootstrap 抽样，使用 3,000 次重采样。撤回实验每语独立从该语 512 道训练侧机制题配对重采样。撤回点与开发集曲线分开，训练侧样本曾用于历史课程。用同顺序第 125 步 SeqLoRA 的当前语作锚，当前语点估计在 ±1 pp 内视为相近，区间另报。这个匹配规则不等于统计非劣检验，开发集挑出的点也不构成独立确认。全程未使用官方测试挑点。

## P0 原始输出与干预强度审计

### A 功能撤回

原实验在选择集的三个剂量都未通过 UR 门槛。12.5% 的机制集诊断中，功能撤回比 P1 恢复 SW **3.42 pp**，与同范数整体撤回的 SW 差 **−0.26 pp**、四旧语均值差 **−1.49 pp**，均见上一轮配对区间。共同合法子集仍有 SW 恢复，作为内容恢复的辅助证据。

新审计直接计算每个 LoRA 模块的有效权重扰动 `||(alpha/r)(B_new A_new − B_P1 A_P1)||_F`，再对模块平方和开根。这一量使用已保存的适配器矩阵，无需实例化基座。在五语固定的 2,560 条机制提示中，与 P1 比较逐题自由生成是否发生变化。

| 12.5% 干预 | adapter L2 | 有效权重 L2 | 原始生成变化题数 / 2,560 | SW 共同合法输出中的槽位变化题数 |
| --- | ---: | ---: | ---: | ---: |
| 整体 | 0.3796 | 0.3840 | 190 | 52 / 501 |
| 功能 | 0.3796 | 0.5161 | 458 | 122 / 499 |
| 随机 | 0.3796 | 0.3319 | 68 | 13 / 501 |
| 旧答案损失 | 0.3796 | 0.5159 | 593 | 159 / 498 |
| 格式 | 0.3796 | 0.5136 | 551 | 145 / 499 |

功能干预的有效权重扰动约比整体大 **34%**，而且改变了更多输出。因此对当前实现为 **NO-GO**，对有效强度匹配后能否定位可分离功能方向为 **INCONCLUSIVE**。本轮只审计既有模型。 [逐模块有效权重、固定提示和配对重算](AB_AUDIT.json)

### B 严格历史平行回放

复核三组原始逐题输出哈希后，平行组对随机的四旧语平均 F1 差为 **−0.57 pp**，对同标签异源为 **−0.22 pp**。前者的区间在零以下，后者跨零。平行组和同标签异源组各用了 60 个不同旧源 ID，随机用了 85 个。就本课程、训练种子和固定预算，继续将同源优先选样作为主方法为 **NO-GO**。 [B 训练与数据审计](../massive-mechanisms-v1/RESULTS_ZH.md)

- **原顺序的匹配早停。** SeqLoRA 94 对 125 的 UR 差为 −0.07 [−1.62, +1.48]，SW 为 +3.81 [+2.36, +5.18]，四旧语均值为 +1.53 [+0.70, +2.30]。该对照共享阶段起点，点估计处于预设的 1 pp 内。原顺序 Replay 94 对 Replay 125 同样以 0.68 pp 的当前语代价换来 +3.13 pp SW 保留。Replay 125 比 SeqLoRA 125 高 1.34 pp SW，但比 SeqLoRA 94 低 2.47 pp。
- **匹配较低学习率。** 原顺序 Full-FT 1e-5 与 Replay 第 94 步的 UR 差 −0.20 [−2.31, +1.90]，旧语均值差 +0.18 [−0.92, +1.33]。1e-5 全参比自身 SW 阶段终点仍掉 4.17 pp。绝对终点与自身变化需要同时看。
- **交换顺序后仍有残余。** Replay 125 相比 SeqLoRA 125 的 SW 当前分差 +0.02 [−1.35, +1.36]，UR 终点差 +1.29 [−0.06, +2.59]，同时自身 UR 阶段前后差 −2.22 [−3.84, −0.57]。老任务曲线出现相反方向的变化，四旧语平均会掩盖残余损失。两条完整 SeqLoRA 与 Replay 轨迹的阶段起点不同，终点差不能全部归因于最后阶段回放。
- **撤回诊断。** 在独立训练侧机制集上，功能撤回 12.5% 的点同时低于整体撤回 12.5% 的当前 UR、SW 及四旧语均值。当前实验中的点被整体撤回支配，但有效扰动不同，且该对照与官方开发集早停曲线使用不同的评估样本，分别作图。

## P2 梯度信号预测

在 UR→SW 的 LoRA Replay 分支，从 P0 计算 256 个旧语样本与 64 个新语样本的梯度。旧语中 185 题含金标槽位，18 题在第 125 步的逐题生成槽位 F1 下降，进入留一语言预测统计。下表比较预测第 125 步旧题 F1 损失的平均绝对误差（MAE，0–1，越小越好）。改善为基线 MAE 减当前 MAE，区间按同题配对重采样，只反映这些留出预测的抽样波动。

| 特征组 | 留一语言 MAE | 相对简单基线的改善（95% 区间） | Spearman |
| --- | ---: | ---: | ---: |
| 初始答案损失、答案梯度范数、随机方向 | 0.1735 | — | 0.032 |
| 加内容梯度 × 实际更新 | 0.1785 | −0.0050 [−0.0095, −0.0005] | 0.043 |
| 加完整答案梯度 × 实际更新 | 0.1905 | −0.0170 [−0.0333, −0.0012] | 0.342 |
| 加格式梯度 × 实际更新 | 0.1808 | −0.0073 [−0.0185, +0.0038] | 0.110 |

实际完整答案更新内积有排序信号，但预测误差上升。阶段前可计算的新语方向与内容梯度没有稳定的预测增量，第 31 步也未过判据。因此当前梯度代理 **NO-GO**。局限为单阶段、单训练种子、来自训练划分的含槽样本和较少的发生遗忘样本。梯度 GPU 耗时 496 秒，三阶段解码累计 61 秒，另有加载开销。
